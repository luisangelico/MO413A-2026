## Project Overview

This is a **Graph Attention Network (GAT) research project** for cancer classification using TCGA melanoma gene expression data. The project uses PyTorch Geometric to build patient-specific protein-protein interaction (PPI) graphs and classify tumor samples into three categories: Primary Tumor, Metastasis, and Healthy Tissue.

## Project Structure

```
gat/
├── baseline.ipynb              # Main Jupyter notebook for data processing, training, and evaluation
├── requirements.txt            # Python dependencies
├── app.py                      # Streamlit visualization app (generated by notebook)
├── proxy-fix-bundle/          # SSL/TLS certificates for proxy environments
│   ├── allCAbundle.pem        # Combined CA certificate bundle

│   └── selfSignedCAbundle.pem # Self-signed CA certificates
├── data/processed/            # Cached datasets and model checkpoints (created on first run)
└── *.csv                      # Pre-computed results (attention weights, embeddings, metadata)
```

## Architecture

### Data Pipeline
1. **Gene Expression Data**: Downloads TCGA-SKCM RNA-seq data (TPM normalized) from UCSC Xena Browser
2. **Gene Selection**: Filters top K most variable genes (default: 500 genes)
3. **PPI Network**: Queries STRING database API for physical protein-protein interactions with confidence threshold (0-1000 scale)
4. **Graph Construction**: Creates one PyTorch Geometric `Data` object per patient where:
   - Nodes = genes with log-transformed expression values as features
   - Edges = protein-protein interactions from STRING
   - Label = sample type extracted from TCGA barcode (01=Primary, 06=Metastasis, 11=Normal)

### Model Architecture (GATv2Classifier)
- **Layer 1**: GATv2Conv with 4 attention heads (1 → 64 channels per head = 256 total)
- **Layer 2**: GATv2Conv with 1 attention head (256 → 64 channels)
- Each layer followed by LayerNorm, ELU activation, and dropout (p=0.4)
- **Readout**: Global mean pooling across nodes
- **Classifier**: Linear layer (64 → 3 classes)

The first GAT layer's attention weights are extracted for visualization.

### Training Configuration
Key hyperparameters defined at the top of `baseline.ipynb`:
- `NUM_NODES`: Number of top variable genes (default: 500)
- `CONFIDENCE_THRESHOLD`: STRING PPI confidence cutoff (default: 500)
- `PROCESSED_DATASET_PATH`: Directory for cached processed datasets
- `BATCH_SIZE`: Training batch size (default: 32)
- `NUM_EPOCHS`: Training epochs (default: 5000)
- `CHECKPOINT_INTERVAL`: Save frequency (default: every 500 epochs)

The loss function uses class weights inversely proportional to class frequency to handle imbalanced data.

### Checkpointing System
- Checkpoints saved to timestamped run directories: `run_YYYYMMDD_HHMMSS/`
- Resume training by setting `CHECKPOINT_PATH = [directory, filename]` and `STOPPED_EPOCH`
- Only model weights are saved (`.pt` files), not full model objects

### Visualization (Streamlit App)
The `app.py` file creates an interactive graph visualization showing:
- Patient-level predictions with confidence scores
- Spring-layout graph with nodes colored by gene expression
- Edges colored by attention weight (orange → dark red gradient)
- Two modes: subgraph (hide low-attention edges) or full graph (show all edges with highlighting)
- Deployed via ngrok tunnel for Colab access

## Development Workflow

### Setup
Install required dependencies:
```bash
pip install -r requirements.txt
```

Or manually:
```bash
pip install torch torch_geometric requests pandas numpy streamlit plotly networkx
```

### Running the Notebook
This project runs locally in Jupyter with the following workflow:

1. Set control variables at the top of the notebook
2. Run dataset processing (or load cached `.pt` file if available)
3. Train model (or resume from checkpoint)
4. Launch Streamlit visualization app locally

### Key Control Variables
Before running, configure these variables in the second cell:
- `PROCESSED_DATASET_PATH`: Where to cache/load processed graphs (default: `./data/processed/`)
- `CHECKPOINT_PATH`: Set to `["dir", "file.pt"]` to resume training, or `None` to start fresh
- `STOPPED_EPOCH`: If resuming, the last completed epoch number

### Dataset Caching
Processed datasets are saved as `tcga_pacientes_{NUM_NODES}_{CONFIDENCE_THRESHOLD}.pt` to avoid re-downloading and re-processing on every run. The notebook checks for cached files before hitting UCSC Xena or STRING APIs.

### Running the Visualization App
After training, run the Streamlit app:
```bash
streamlit run app.py
```
The app will be available at http://localhost:8501. Configure the dataset and model paths in the sidebar.

## SSL/TLS Certificate Configuration

The `proxy-fix-bundle/` directory contains CA certificate bundles for environments behind corporate proxies or with custom SSL certificates. These may be needed when downloading data from external sources (UCSC Xena, STRING API).

### Using Custom Certificates

If you encounter SSL certificate errors when downloading data, configure Python to use these certificates:

```python
import os
os.environ['REQUESTS_CA_BUNDLE'] = './proxy-fix-bundle/allCAbundle.pem'
# Or for conda environments:
os.environ['SSL_CERT_FILE'] = './proxy-fix-bundle/allCAbundle.pem'
```

Add this to the top of the dataset processing cell before making any network requests.

### Certificate Files
- `allCAbundle.pem`: Combined bundle with all CA certificates (use this first)
- `bundleCA.pem`: Standard CA certificates only
- `selfSignedCAbundle.pem`: Self-signed certificates (for corporate environments)

## Important Notes

### TCGA Barcode Parsing
Sample type is extracted from the 4th dash-separated field of TCGA barcodes:
- `01` → Primary tumor (class 0)
- `06` → Metastatic tumor (class 1)  
- `11` → Normal/healthy tissue (class 2)

Other sample types are filtered out.

### STRING API Usage
The PPI network is queried using POST requests to `https://string-db.org/api/tsv/network` with:
- Species: 9606 (Homo sapiens)
- Network type: physical interactions only
- Required score: configured via `CONFIDENCE_THRESHOLD`


### Model State Management
- **Training**: Only `model.state_dict()` is saved (weights only)
- **Loading**: Model architecture must be re-instantiated before calling `load_state_dict()`
- The GATv2Classifier class definition must be available in both training and visualization code
