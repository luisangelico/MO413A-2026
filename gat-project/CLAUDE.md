# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Graph Attention Network (GAT) project for melanoma classification. Uses
PyTorch Geometric to build per-sample protein-protein interaction (PPI) graphs
from gene expression data and classify samples into Primary Tumor / Metastasis
/ Normal Tissue.

## Layout

```
gat-project/
├── src/                  # importable package (config, model, train, evaluate, predict)
├── scripts/              # entry-point scripts (download_toil.py, explore_streamlit.py)
├── notebooks/            # Streamlit tutorials
├── docs/
├── archive/              # superseded scripts
├── data/                 # gitignored, generated by download_toil.py
└── README.md             # canonical docs (start here)
```

Run commands as modules from the `gat-project/` directory:
`python -m src.train`, `python -m src.evaluate`, `python -m scripts.download_toil`.

## Single source of truth

- **Dataset path** lives in `src/config.py` as `DATASET_FILE`. Every script
  imports it. Do not hardcode dataset paths anywhere else.
- **Model architecture** lives in `src/model.py` as `GATv2Classifier`. Do not
  re-define the class in scripts. Use `load_model()` / `save_model()` — they
  persist a sidecar JSON so checkpoints are self-describing.

## Data Pipeline (`scripts/download_toil.py`)

1. Pulls TCGA-SKCM + GTEx skin from the UCSC Xena **TOIL recompute** (joint
   reprocessing → no batch effects between the two sources).
2. Filters to top-variable genes (default 500), queries STRING for physical PPIs.
3. Builds one PyG `Data` object per sample.

**Important:** TOIL expression values are *already* `log2(TPM+0.001)`. Do not
re-apply `log1p`. The archived `download_data.py` (GDC-Hub TPM) does apply
`log1p`; outputs are not interchangeable.

## Labels
- `0` = Primary Tumor (TCGA sample type 'Primary Tumor')
- `1` = Metastasis (TCGA sample type 'Metastatic')
- `2` = Normal Tissue (GTEx skin)

## Training (`src/train.py`)

- Stratified 70/15/15 train/val/test split, seeded (`SEED=42`), saved to `splits.npz`
- Class weights computed from the **train set only** (no leakage)
- Best model selected on **validation loss**, evaluated every epoch
- Early stopping with patience 30
- `DROP_NORMAL_CLASS = False` for the TOIL dataset (plenty of normals);
  keep this `True` only if reverting to the legacy 472-patient TCGA-SKCM-only set

## Evaluation (`src/evaluate.py`)

Loads the saved `splits.npz` and reports metrics on the **held-out test split
only**. If splits are missing it warns loudly and falls back to full-dataset
eval — that warning means data leakage and should be fixed by retraining.

## SSL / Proxy

`download_toil.py` and the archived `download_data.py` both honor:
- `REQUESTS_CA_BUNDLE=/path/to/bundle.pem` — preferred
- `GAT_INSECURE_SSL=1` — opt-in `verify=False` escape hatch

## When making changes

- Don't reintroduce duplicate model class definitions — import from `src.model`.
- Don't reintroduce hardcoded dataset paths — import `DATASET_FILE` from `src.config`.
- The `archive/` directory contains superseded scripts; treat as read-only history.
