# GAT Melanoma Classification

Graph Attention Network for classifying TCGA-SKCM melanoma + GTEx skin samples
using protein–protein interaction (PPI) graphs from STRING.

Each sample is a graph: **nodes** = top-variable genes (with TPM expression as
features), **edges** = STRING physical PPI links. A two-layer GATv2 produces a
graph-level prediction (Primary Tumor / Metastasis / Normal).

## Layout

```

├── src/                    # importable package
│   ├── config.py           # paths and constants (single source of truth)
│   ├── model.py            # GATv2Classifier + save/load helpers

│   ├── evaluate.py         # held-out test evaluation
│   └── predict.py          # interactive CLI
├── scripts/

```

## Quickstart

```bash
pip install -r requirements.txt

# 1. Download + process data (~3 GB cached on first run)
python -m scripts.download_toil

# 2. Train (stratified split, early stopping, val-loss best-model)
python -m src.train

# 3. Evaluate on the held-out test split
python -m src.evaluate

# 4. Interactive predictions
python -m src.predict
```

> Run commands from the `gat-project/` directory so `src.config`'s relative
> data path resolves correctly.

## Switching the active dataset

`src/config.py` is the single point of control:

```python
DATASET_FILE = PROCESSED_DATASET_PATH / f"toil_skin_{NUM_NODES}_{CONFIDENCE_THRESHOLD}.pt"
```

Change that line and every script picks it up.

## Training methodology

- Stratified 70/15/15 train/val/test split (seeded, saved to `splits.npz`)
- Class weights computed from the **train** set only (no leakage)
- **Best model selected on validation loss**, evaluated every epoch
- Early stopping (patience = 30)
- Adam + weight decay 5e-4, dropout 0.4
- Final test-set evaluation runs on the held-out split only

## Model

`GATv2Classifier` in `src/model.py`:
- GATv2Conv 1 → 64 (×4 heads = 256) → LayerNorm → ELU → dropout
- GATv2Conv 256 → 64 (1 head) → LayerNorm → ELU
- Global mean pool → Linear → logits

Architecture config is saved as a sidecar `.json` next to each `.pt`, so
checkpoints are self-describing and `load_model()` rebuilds the right shape
automatically.

## Notes

- **TOIL values are already log2(TPM+0.001)** — `download_toil.py` does *not*
  re-apply `log1p`. The legacy `archive/download_data.py` (GDC-Hub TPM) does;
  don't mix the two outputs.
- SSL: if you sit behind a proxy with custom CAs, set
  `REQUESTS_CA_BUNDLE=/path/to/bundle.pem` before running, or use
  `GAT_INSECURE_SSL=1` as a last-resort opt-in.
