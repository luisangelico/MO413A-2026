Where the data comes from

In one sentence. Every sample in this project is a patient's gene-expression measurement, paired with the protein–protein interaction (PPI) network of the genes we measured, packaged together as a single graph the GAT can consume.

The two data sources

1. Tumor expression — TCGA-SKCM via UCSC Xena TOIL

Primary and metastatic melanoma samples come from TCGA-SKCM (The Cancer Genome Atlas, skin cutaneous melanoma), as reprocessed by the UCSC Xena TOIL pipeline. TOIL applies a single, uniform alignment + quantification pipeline to every sample, which is essential when mixing data from different sources.

Values are reported as log2(TPM + 0.001) — "how much each gene is being expressed, on a log scale."

2. Benign-melanocyte expression — GEO GSE112509 (nevi)

The healthy-comparator class is laser-microdissected melanocytic nevi from GSE112509 (Hartmann et al., 2018). Nevi are benign melanocytic lesions — same cell lineage as melanoma — so the contrast we learn is malignant-vs-benign melanocyte, not melanocyte-vs-skin.

Values are DESeq2 size-factor-normalized counts from the GEO supplementary file. We log2(x + 1)-transform them to bring them onto the same kind of log scale as TOIL.

3. Protein interactions — STRING

Edges between genes in each sample's graph come from STRING-DB, a database of known protein–protein interactions. We use only physical interactions (proteins that actually bind) at confidence threshold ≥ 200.

The same edge set is used for every sample; only the node features (expression values) change patient to patient.

4. Cross-cohort harmonization

TCGA-SKCM and GSE112509 come from different pipelines, so raw values aren't directly comparable. We can't use per-cohort z-scoring here: the nevus class lives entirely in GSE112509 (cohort and class 2 are perfectly confounded), so per-cohort centering would force every gene's nevus mean to match its tumor mean — erasing the signal we want to learn.

Instead: (i) shift GSE onto the TCGA scale by subtracting a single global offset (the difference of the two cohorts' median expression), then (ii) standardize both cohorts using TCGA-train per-gene mean & std as the reference frame. This corrects the platform-level offset without destroying per-gene differences between nevi and tumors.

Limitation. Not full batch correction — only joint reprocessing from FASTQs would be. The shift is global, not per-gene, so cohort-specific gene-level biases can still leak in.

Why nevi, not skin?

Earlier versions of this project used GTEx skin as the healthy class. That was a mistake — and a biologist on the team flagged it. Melanocytes do not keratinize. Keratinization is the job of keratinocytes, a different cell type that makes up the bulk of the epidermis. GTEx "skin" is whole-tissue epidermis, so it is overwhelmingly keratinocytes — only a small fraction of cells are melanocytes.

A model trained against GTEx skin therefore ends up learning a melanocyte-vs-keratinocyte signature: keratinization genes (KRT*, LOR, FLG, IVL) dominate. That is a tissue-composition artifact, not melanocyte biology.

Replacing GTEx skin with nevi from GSE112509 fixes this: nevi are themselves melanocytic, so the contrast becomes malignant melanocyte (TCGA-SKCM tumors) vs benign melanocyte (nevi). Pigmentation / melanocyte-lineage genes (MITF, TYR, PMEL, MLANA, DCT, SOX10) become biologically interpretable signal rather than noise pushed aside by keratin genes.

What a real sample looks like

One representative sample per class — picked as the sample closest to its class centroid in expression space. Values are the per-cohort gene-wise z-scores actually fed into the model: + means the gene is more expressed than that cohort's average, − means less. The genes shown are curated, not the model's selection.

Read the keratinization rows. If this dataset were still contrasting melanoma against bulk skin, you'd expect KRT5 / KRT14 / LOR / FLG to dominate the Normal class. With nevi as the comparator, both nevus and tumor samples are melanocytic — keratinization is not the discriminator anymore. The pigmentation genes (MITF, TYR, MLANA, …) are now the biologically meaningful axis.

What each sample looks like

  • 1000 genes (nodes) per sample — the genes whose expression varies most across the cohort. Less variable genes are dropped because they carry little discriminative information.
  • 196 directed edges per sample (≈ 98 unique interactions, both directions kept so message-passing can flow either way).
  • Average degree 0.20; max degree 16; 936 genes have no PPI partners in this panel and act as isolated nodes — the model still uses their expression directly via self-loops.

Snapshot — class balance, expression distributions, PCA, degree

Four sanity-check views of the dataset before any modeling:

  • Top-left: how many samples per class. Note the nevus class is much smaller than the tumor classes (this is handled in training via class-weighted loss).
  • Top-right: distribution of expression values per class, after the per-cohort z-score harmonization. All three classes sit on the same scale; the per-class differences reflect biology, not pipeline units.
  • Bottom-left: PCA of harmonized expression (no model involved). Nevi separate cleanly from tumors; the harder sub-task is splitting Primary from Metastasis. PC1 + PC2 explain 17.9% of variance.
  • Bottom-right: degree distribution of the PPI graph. A few hub genes have many partners; most have a handful.

The PPI graph — interactive

Force-directed layout of the same PPI network used in every sample's graph. Drag nodes to explore; scroll to zoom; hover a node for gene name, degree, and mean expression. Node color = average expression across the cohort (dark → bright); node size = number of PPI partners. The biggest hubs are pre-labeled.

Why hubs matter for interpretability. Genes with many PPI partners are easy targets for any attention mechanism — they collect information from a lot of neighbors. That's why every attention finding in this project is benchmarked against a node-degree baseline (see the attention interpretability page). An attention ranking that beats degree is doing something the static graph alone can't.

Provenance summary

  • Tumor cohort: TCGA-SKCM (Primary Tumor + Metastasis), via the UCSC Xena TOIL recompute. Quantification: log2(TPM + 0.001).
  • Benign-melanocyte cohort: GEO GSE112509 (Hartmann et al., 2018) — laser-microdissected nevi. Quantification: DESeq2 size-factor-normalized counts, then log2(x + 1).
  • Harmonization: global cohort offset removed (GSE median shifted to TCGA-train median), then both cohorts standardized using TCGA-train per-gene mean & std as the reference frame.
  • Gene panel: top-1000 most-variable genes selected on the train split only (no leakage).
  • Graph: STRING physical PPIs, confidence ≥ 200.
  • Per-sample graph: 1000 nodes, 196 directed edges (shared topology, per-sample expression features).
  • Total samples: 492 (102 Primary Tumor / 367 Metastasis / 23 Benign Nevus).

Pipeline source: scripts/download_toil.py. Active dataset file is set in src/config.py as DATASET_FILE.
