GAT attention — top-30 PPI subgraphs by class

What you're looking at

Each page below shows the protein–protein interaction (PPI) subgraph induced by the top-30 most-attended genes for one class, as seen by the trained Graph Attention Network on the held-out test split. Per-sample edge attention from all three GAT layers is averaged across heads, summed onto destination nodes, then averaged across correctly classified samples in the class.

What "attention score" means

Inside each GAT layer, every directed edge i → j in the PPI graph carries an attention coefficient α(i→j) — a number the model learns that says how much node j should listen to node i when updating its representation. For a fixed destination node j, the α(i→j) values are softmax-normalized across j's incoming neighbors (including a self-loop), so each individual α lies in [0, 1] and the values incoming to j sum to 1 (per attention head, per layer).

We turn this into a per-gene importance score in three steps:

  1. Per sample, per layer: mean α across the 4 attention heads, then sum the incoming α onto each gene (its destination).
  2. Across the 3 GAT layers: sum the per-layer values (so a gene that is consistently attended deep in the network scores higher than one only briefly attended in layer 1).
  3. Across samples: average over correctly classified test-set samples within the class.

The resulting score is unitless and approximately on a [0, ~3] scale (3 layers × softmax-normalized incoming attention). Only relative differences between genes matter — a gene with score 0.04 versus 0.01 attracted four times the attention, even though both are "small" numbers. All scores reported here are these per-class averages.

How to read the visualization

  • Node size = per-class mean attention importance (bigger = the model relied on this gene more when classifying samples in this class).
  • Node color = Tumor − Normal differential attention (red = preferentially attended in tumor samples, blue = preferentially in normal skin, white ≈ neutral).
  • Edges = STRING physical PPIs (confidence ≥ 200) between these genes. Layout is force-directed (Barnes-Hut); you can drag nodes.
  • Hover a node for: gene symbol, attention score, Tumor − Normal score, and gene-set membership.

Why this matters

A GAT trained only on gene expression and PPI topology can be inspected for which genes drove each prediction. If the top-attended genes recover known melanoma biology (melanocyte lineage markers, immune infiltrate signature, cornified-envelope genes for normal skin), the model is learning interpretable signal rather than spurious patterns. The contrast rankings (Metastasis − Primary, Tumor − Normal) are the most informative — they isolate what attention does differently across classes, beyond the static PPI hub structure.

Sanity check. A node-degree baseline ranking is included in the companion bar charts and heatmap. Where attention beats degree (e.g. Metastasis − Primary recovering keratin/skin genes at p ≈ 2×10⁻⁵ vs. p ≈ 5×10⁻³ for degree alone), the GAT is genuinely learning class-specific importance — not just attending to PPI hubs.
Why some nodes look disconnected. Each subgraph is the induced subgraph over the top-30 attended genes. An isolated node means the gene was attended to, but its STRING PPI partners were not themselves in the top-30 for that class — its edges still exist in the full graph, just not within this filtered view.
