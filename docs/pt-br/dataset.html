De onde vêm os dados

Em uma frase. Cada amostra deste projeto é a medida de expressão gênica de um paciente, pareada com a rede de interações proteína–proteína (PPI) dos genes medidos, empacotadas como um único grafo que a GAT pode consumir.

As duas fontes de dados

1. Expressão tumoral — TCGA-SKCM via UCSC Xena TOIL

As amostras de melanoma primário e metastático vêm do TCGA-SKCM (The Cancer Genome Atlas, melanoma cutâneo), reprocessadas pelo pipeline UCSC Xena TOIL. O TOIL aplica um único pipeline uniforme de alinhamento + quantificação a todas as amostras, o que é essencial ao misturar dados de fontes diferentes.

Os valores são reportados como log2(TPM + 0,001) — "quanto cada gene está sendo expresso, em escala log".

2. Expressão de melanócitos benignos — GEO GSE112509 (nevos)

A classe comparadora saudável é composta por nevos melanocíticos microdissecados a laser do GSE112509 (Hartmann et al., 2018). Nevos são lesões melanocíticas benignas — mesma linhagem celular do melanoma — então o contraste que aprendemos é melanócito maligno vs benigno, e não melanócito vs pele.

Os valores são contagens normalizadas por size-factor do DESeq2 obtidas no arquivo suplementar do GEO. Aplicamos a transformação log2(x + 1) para colocá-las na mesma escala log do TOIL.

3. Interações proteicas — STRING

As arestas entre genes no grafo de cada amostra vêm do STRING-DB, uma base de interações proteína–proteína conhecidas. Usamos apenas interações físicas (proteínas que de fato se ligam) com confiança ≥ 200.

O mesmo conjunto de arestas é usado para todas as amostras; apenas as features dos nós (valores de expressão) mudam de paciente para paciente.

4. Harmonização entre coortes

TCGA-SKCM e GSE112509 vêm de pipelines diferentes, então valores brutos não são diretamente comparáveis. Não dá para usar z-score por coorte aqui: a classe nevo está totalmente em GSE112509 (coorte e classe 2 são perfeitamente confundidas), então centralizar por coorte forçaria a média de nevo de cada gene a igualar a média do tumor — apagando o sinal que queremos aprender.

Em vez disso: (i) deslocamos o GSE para a escala do TCGA subtraindo um único offset global (diferença das medianas de expressão das duas coortes); depois (ii) padronizamos ambas as coortes usando média e desvio por gene do TCGA-treino como referência. Isso corrige o offset de plataforma sem destruir as diferenças por gene entre nevos e tumores.

Limitação. Não é correção de batch completa — só reprocessamento conjunto a partir dos FASTQs seria. O deslocamento é global, não por gene, então vieses específicos por gene de cada coorte ainda podem vazar.

Por que nevos, e não pele?

Versões anteriores deste projeto usavam pele do GTEx como classe saudável. Foi um erro — apontado por um biólogo da equipe. Melanócitos não queratinizam. A queratinização é função dos queratinócitos, um tipo celular distinto que forma a maior parte da epiderme. A "pele" do GTEx é epiderme inteira, então é majoritariamente queratinócitos — apenas uma pequena fração das células são melanócitos.

Um modelo treinado contra a pele do GTEx acaba aprendendo, portanto, uma assinatura melanócito vs queratinócito: genes de queratinização (KRT*, LOR, FLG, IVL) dominam. Isso é um artefato de composição tecidual, não biologia melanocítica.

Substituir a pele do GTEx por nevos do GSE112509 corrige isso: nevos também são melanocíticos, então o contraste passa a ser melanócito maligno (tumores TCGA-SKCM) vs melanócito benigno (nevos). Genes de pigmentação / linhagem melanocítica (MITF, TYR, PMEL, MLANA, DCT, SOX10) tornam-se sinal biologicamente interpretável, em vez de ruído ofuscado pelos genes de queratina.

Como é uma amostra real

Uma amostra representativa por classe — escolhida como a mais próxima do centroide da classe no espaço de expressão. Os valores são os z-scores por coorte e por gene de fato alimentados ao modelo: + significa que o gene é mais expresso que a média da coorte, − significa menos. Os genes mostrados são curados, não selecionados pelo modelo.

Olhe as linhas de queratinização. Se este conjunto ainda contrastasse melanoma contra pele inteira, esperaríamos KRT5 / KRT14 / LOR / FLG dominando a classe Normal. Com nevos como comparador, tanto nevos quanto tumores são melanocíticos — queratinização deixou de ser o discriminador. Os genes de pigmentação (MITF, TYR, MLANA, …) passam a ser o eixo biologicamente significativo.

Como é cada amostra

  • 1000 genes (nós) por amostra — os genes cuja expressão mais varia ao longo da coorte. Genes menos variáveis são descartados por carregarem pouca informação discriminativa.
  • 196 arestas direcionadas por amostra (≈ 98 interações únicas, ambas as direções preservadas para que a passagem de mensagens flua nos dois sentidos).
  • Grau médio 0,20; grau máximo 16; 936 genes não têm parceiros de PPI neste painel e atuam como nós isolados — o modelo ainda usa sua expressão diretamente, via self-loops.

Resumo — balanço de classes, distribuição de expressão, PCA, grau

Quatro visualizações de sanidade do conjunto antes de qualquer modelagem:

  • Superior esquerdo: quantas amostras por classe. Note que a classe nevo é bem menor que as tumorais (isso é tratado no treino via perda ponderada por classe).
  • Superior direito: distribuição dos valores de expressão por classe, após a harmonização z-score por coorte. As três classes estão na mesma escala; as diferenças entre classes refletem biologia, não unidades de pipeline.
  • Inferior esquerdo: PCA da expressão harmonizada (sem nenhum modelo envolvido). Nevos separam-se claramente dos tumores; a sub-tarefa mais difícil é separar Primário de Metástase. PC1 + PC2 explicam 17,9% da variância.
  • Inferior direito: distribuição de grau do grafo PPI. Alguns genes hub têm muitos parceiros; a maioria tem poucos.

O grafo PPI — interativo

Layout force-directed da mesma rede PPI usada no grafo de toda amostra. Arraste nós para explorar; role para dar zoom; passe o mouse sobre um nó para ver nome do gene, grau e expressão média. Cor do nó = expressão média na coorte (azul = negativa, branco ≈ 0, vermelho = positiva); tamanho do nó = número de parceiros PPI. Os maiores hubs já vêm rotulados.

Por que hubs importam para interpretabilidade. Genes com muitos parceiros PPI são alvos fáceis para qualquer mecanismo de atenção — eles coletam informação de muitos vizinhos. Por isso toda análise de atenção neste projeto é comparada contra um baseline de grau (veja a página de interpretabilidade da atenção). Um ranking de atenção que supera o grau está fazendo algo que o grafo estático sozinho não consegue.

Resumo de proveniência

  • Coorte tumoral: TCGA-SKCM (Tumor Primário + Metástase), via reprocessamento UCSC Xena TOIL. Quantificação: log2(TPM + 0,001).
  • Coorte de melanócitos benignos: GEO GSE112509 (Hartmann et al., 2018) — nevos microdissecados a laser. Quantificação: contagens normalizadas por size-factor do DESeq2, seguidas de log2(x + 1).
  • Harmonização: offset global da coorte removido (mediana do GSE deslocada para a mediana do TCGA-treino) e ambas as coortes padronizadas usando média e desvio por gene do TCGA-treino como referência.
  • Painel de genes: top-1000 genes mais variáveis, selecionados apenas na divisão de treino (sem leakage).
  • Grafo: PPIs físicas do STRING, confiança ≥ 200.
  • Grafo por amostra: 1000 nós, 196 arestas direcionadas (topologia compartilhada, features de expressão por amostra).
  • Total de amostras: 492 (102 Tumor Primário / 367 Metástase / 23 Nevo Benigno).

Origem do pipeline: scripts/download_toil.py. O arquivo de dataset ativo é definido em src/config.py como DATASET_FILE.
